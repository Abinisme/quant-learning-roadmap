指标概览与分类对比

五大经典指标 · 适用场景 · 一句话定位

五大指标速览
指标类型核心用途适用市场信号频率一句话
MACD趋势跟踪判断趋势方向与强度趋势市最佳中"用两均线的差值画第三根线"
RSI震荡指标超买超卖、动能强弱震荡市最佳高"过去N天涨了多少 vs 跌了多少"
布林带波动率+通道价格极端位置判断震荡市中"用标准差做弹性围栏"
KDJ震荡指标短线超买超卖、背离短线震荡极高"用最高最低价定位收盘价位置"
ATR波动率止损设置、仓位计算所有市场—"不告诉你方向，只告诉你波动多大"
趋势指标 vs 震荡指标
趋势类（MACD、MA）
  • 在趋势市中方向明确、信号可靠
  • 在震荡市中频繁假信号、反复止损
  • 信号滞后于价格（均线的本质属性）
  • 适合中长线、不适合短线频繁交易
震荡类（RSI、KDJ）
  • 在震荡市中精准捕捉转折点
  • 在强趋势市中持续"超买/超卖"，信号失效
  • 信号领先于价格（反映动能变化）
  • 适合短线、对噪音敏感
互补搭配原则

单一指标永远不够——趋势指标+震荡指标+波动率指标的组合才能覆盖不同市场环境。经典铁三角：MACD（方向）+ RSI（力度）+ ATR（仓位）。

当 MACD 零轴上方 + RSI 40-60 + ATR 低位收窄 → 趋势初期即将启动，是最佳入场窗口。

MACD — 指数平滑异同移动平均线

Gerald Appel · 1979 · 由三条线组成的趋势核心指标

计算原理（三步）
1
DIF = EMA(12) - EMA(26) ——快慢均线差值，正值=多头市场
2
DEA = EMA(DIF, 9) ——对 DIF 再做一次平滑，信号线
3
柱状线 = 2 × (DIF - DEA) ——差值放大 2 倍，红柱=多头加强，绿柱=空头加强
MACD柱变化 = 今天的柱 - 昨天的柱
柱由绿翻红且变大 → 多头动能增强（买入确认）
买卖信号与实战用法
信号条件可靠性
金叉买入DIF 从下方向上穿越 DEA中（需结合零轴位置判断）
死叉卖出DIF 从上方向下穿越 DEA中
零轴判断DIF > 0 → 多头市场；DIF < 0 → 空头市场高（趋势环境判断）
零轴上金叉DIF 在零轴上方金叉 DEA较高（顺势做多）
零轴下死叉DIF 在零轴下方死叉 DEA较高（顺势做空）
MACD 背离——最强大的信号但最难判断
顶背离 → 见顶信号

股价创新高，但 MACD 的 DIF 或柱状线高点越来越低。说明上涨动能衰竭，趋势可能反转。背离次数越多（通常 2-3 次），反转概率越大。

底背离 → 见底信号

股价创新低，但 MACD 的 DIF 或柱状线低点越来越高。说明下跌动能衰竭，趋势可能反转。底背离后需要放量确认——缩量底背离可能是陷阱。

⚠️ 实战要点：背离是"必要条件"不是"充分条件"。顶背离后股价可能继续涨（钝化），需要等 MACD 死叉确认。底背离后可能继续跌，需要等放量阳线确认。

RSI — 相对强弱指标

Welles Wilder · 1978 · 0-100 区间的动能振荡器

计算原理
RS = N 日内平均上涨幅度 / N 日内平均下跌幅度
RSI = 100 - 100/(1 + RS)

默认参数 N=14（Wilder 原版）。RSI 的核心思想：如果最近 14 天几乎天天涨，RS≈无穷大→RSI≈100；天天跌→RS≈0→RSI≈0。

短线交易可用 N=6-9（更敏感）；中长线用 N=14-21（更平滑）。周期越短假信号越多。
信号体系与参数配置
区域RSI 范围含义操作
超买区> 70市场过热，买盘可能枯竭考虑卖出
强势区50-70多头占优但未过热持有或轻仓
中性区30-70方向不明确观望
弱势区30-50空头占优但未恐慌轻仓或观望
超卖区< 30市场恐慌，卖盘可能枯竭考虑买入

牛市/强趋势中 RSI 可持续 70-80+，此时超买信号不可靠。熊市/暴跌中 RSI 可跌至 10-20 且持续数日。

RSI 的高级用法
RSI 背离

与 MACD 背离同理——价格创新高但RSI高点下移=顶背离；价格创新低但RSI低点上移=底背离。RSI 背离通常比 MACD 背离更早出现。

Failure Swing（失败摆动）

RSI 突破 70 后回落→再次上攻但未破 70→再下跌。这是比单纯 RSI>70 更可靠的见顶信号。Wilder 本人最推崇的信号。

布林带 — Bollinger Bands

John Bollinger · 1980s · 以标准差构建的弹性通道

构成与参数
中轨 = MA(20)
上轨 = 中轨 + 2 × σ(20)
下轨 = 中轨 - 2 × σ(20)

σ 是过去 20 日的收盘价标准差。上轨和下轨之间包含了约 95% 的价格（假设正态分布）。价格突破上/下轨属于小概率事件。

参数 20/2 是标准配置。短线可调整为 10/1.5（更窄更敏感），长线可调整为 50/2.5（更宽更稳定）。

核心信号——带宽是关键
信号条件含义
带宽收窄上轨-下轨处于历史低位暴风雨前的宁静——即将大幅波动
触及上轨收盘价 > 上轨超买，但强势股可沿上轨持续上行
触及下轨收盘价 < 下轨超卖，但弱势股可沿下轨持续下行
下轨反弹触下轨后阳线收回均值回归买入信号
上轨回落触上轨后阴线收回均值回归卖出信号
布林带的两种互补策略
震荡市：均值回归

价格在上下轨之间来回波动。触及下轨→买入，回到中轨或触及上轨→卖出。核心前提：市场没有明显趋势。

趋势市：突破跟随

带宽收窄后突然放大+价格突破上轨→趋势启动，顺势做多。此时不要做均值回归（价格会沿上轨持续上行）。

⚠️ 关键：带宽收窄（Squeeze）是布林带最有价值的信号——它告诉你"暴风雨要来了"，但不告诉你方向。方向需要由 MACD 或突破方向来确认。

KDJ — 随机指标

George Lane · 1950s · 由 K/D/J 三线构成的短线利器

计算原理（直观版）
RSV = (收盘价 - N日最低) / (N日最高 - N日最低) × 100
K = 2/3 × 前K + 1/3 × RSV
D = 2/3 × 前D + 1/3 × K
J = 3K - 2D

默认 N=9。RSV（Raw Stochastic Value）代表收盘价在过去 9 日价格区间中的位置。收盘在最高点→RSV=100；收在最低点→RSV=0。

信号系统
信号条件可靠性
金叉买入K 线从下方向上穿越 D 线中低（需看位置）
死叉卖出K 线从上方向下穿越 D 线中低
低位金叉K/D 在 20 以下金叉较高（超卖区转折）
高位死叉K/D 在 80 以上死叉较高（超买区转折）
J 值极端J > 100 或 J < 0极值反转信号
钝化K/D 持续在 80+ 或 20- 多日强趋势中常见，此时信号失效
KDJ 的特殊注意事项

钝化陷阱：强势上涨中 KDJ 会持续在 80-100 钝化数周，如果此时做空是逆势操作。强趋势中 KDJ 的超买信号应该被忽略，只用金叉/死叉判断短期节奏。

最佳场景：KDJ 在横盘震荡市中表现极好——K/D 在 20-80 之间规律摆动，低吸高抛收益稳定。但一旦趋势启动，应切换至 MACD 或趋势类指标。

ATR — 平均真实波幅

Welles Wilder · 1978 · 衡量波动率而非方向的独特指标

计算原理
TR = max(当日高-当日低, |当日高-昨收|, |当日低-昨收|)
ATR = TR 的 N 日移动平均（默认 N=14）

True Range 的三个值覆盖了：当日振幅、向上跳空、向下跳空。跳空是 ATR 区别于普通振幅计算的关键——它确保隔夜风险被纳入度量。

ATR 单位与价格相同（如 ATR=3.5 元）。它不告诉方向——仅告诉你"市场在震动"。

ATR 的核心用途
用途方法说明
动态止损止损 = 入场价 ± 2×ATR海龟交易法的核心——波动大时放宽止损，波动小时收紧
仓位计算仓位 = 风险金额 / (ATR × 乘数)确保不同品种承担相同风险
趋势强度ATR 上升 = 趋势加速ATR 上升说明动能加强，顺势持有
突破确认突破 + ATR 放大 = 真突破假突破通常伴随着 ATR 下降
ATR 与其他指标的协同

ATR 不产生买卖信号，但它能让其他指标的信号"量化"。RSI 超卖了→买入多少？布林下轨反弹了→止损放哪？这些问题的答案都需要 ATR 参与。ATR 是量化交易中唯一一个"不告诉你做什么但告诉你做多少"的指标。

多指标共振策略

组合使用 · 三重过滤 · 信号质量提升

三重过滤法——从 50% 胜率到 65%

单指标准确率通常 45-55%。三重过滤可以将准确率提升至 60-70%，代价是信号频率大幅降低（从每天 2 次降至每周 1-2 次）。

1
趋势过滤器（MACD 零轴）：DIF > 0 → 只做多/不做空；DIF < 0 → 只做空/不做多。第一层确保你在做"顺大势"的交易。
2
震荡过滤器（RSI/KDJ）：趋势向上时等 RSI < 40（回调末期）再入场；趋势向下时等 RSI > 60（反弹末期）再入场。第二层确保你不在超买/超卖的价格入场。
3
突破确认（布林带/价格行为）：价格突破近期高点（做多）或跌破近期低点（做空）。第三层确保趋势确实在启动，而非假信号。
做多共振模板
指标条件权重
MACDDIF > 0 且 DIF 上穿 DEA（金叉）★★★★★
RSIRSI(14) 从 30-50 区间开始回升★★★★
布林带收盘价从下轨附近开始反弹回中轨★★★
KDJK 线在 30 以下上穿 D 线且 J < 20★★★

指标条件权重

RSIRSI(14) 从 50-70 区间开始回落★★★★
布林带收盘价从上轨附近开始回落到中轨★★★
KDJK 线在 70 以上下穿 D 线且 J > 80★★★

共振策略的关键权衡
✅ 优势
  • 胜率从 45% 提升至 60-70%
  • 大大减少假信号和频繁交易
  • 每次交易有多个理由支持
  • 心理上更有信心执行
⚠️ 代价
  • 信号数量大幅减少（每周1-2次）
  • 可能错过"不完美但能赚钱"的机会
  • 过度过滤可能导致过拟合历史
  • 参数组合膨胀→测试复杂度指数增长

常见陷阱与避坑指南

每个指标都有盲区 · 知道什么不该做比知道该做什么更重要

十大常见错误
#错误为什么错正确做法
1趋势市用震荡指标做反转RSI/KDJ 在强趋势中持续超买不回落先用 ADX/MACD 判断市场状态再选指标
2震荡市用趋势指标追涨杀跌均线在横盘中反复金叉死叉，全是假信号震荡市用布林带/RSI 做均值回归
3只看指标不看价格指标滞后于价格——价格行为才是第一手信息指标是价格变动的影子，不是原因
4参数过度优化把每个指标的参数调到"历史最优"=过拟合用默认参数，或固定一套参数不做频繁调整
5多个同类指标堆叠MACD+MA+布林中轨三个都基于均线→冗余选趋势类1个+震荡类1个+波动类1个
6忽视成交量确认无量突破往往是假突破任何信号都需要成交量放大来确认
7小周期用大参数15分钟K线用 RSI(14) 过于迟钝小周期缩短参数，大周期延长参数
8背离就立刻反向MACD 顶背离后价格可能再涨 10-20%背离是预警，不是执行信号；等确认
9只看日线不看周线日线金叉但周线死叉=逆大势操作多周期共振：周线定方向，日线找入场点
10迷信单一指标的"圣杯"任何指标准确率天花板约 55%组合使用+仓位管理+止损纪律才是稳定盈利的核心
指标使用黄金法则
① 先判断市场状态再选指标（趋势/震荡/转折→MACD/RSI/布林带）
② 趋势类 + 震荡类 + 波动类，三类各选一个（不堆叠同类指标）
③ 默认参数优先（MACD 12/26/9, RSI 14, 布林 20/2, KDJ 9/3/3）
④ 信号需要确认（MACD金叉 + 成交量放大 + 价格突破阻力 = 强度确认）
⑤ 任何一个指标单用的准确率不超过 55%（组合+仓位+止损才是稳定盈利的核心）
